# Practical 7

This code practes the use of pointers to create arrays, It estimates the taylor expansion of eulers number $e$ up to the $n$th order polynomial, where $n$ is given by the user. 

It also dynamically allocates an array, fills it with 1's in each entry and prints it to the terminal.

## How to compile 

gcc pointers.c -o pointers -lm -Wall

## How to use
To execute, run the following propmpt in your terminal
``./pointers``
Next you will be prompted to enter a positive Integer, this will be used to define the order of the polynomial used to estimate $e$.

Finally you will get the complete output of the code.
