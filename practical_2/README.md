# Practical 2

Contains two codes written in C

They can be compiled using 
gcc file.c -o file -lm -Wall

Where file is the name of one of the files

## Conversion.c 
Conversion.c takes an integer, prints the number of digits it has in binary, then prints the number as (i) an int (ii) a float (iii) in binary representation. 

## Sum.c
Sum.c sums the numbers 1/n for n in [1,1000] . It does this both starting at 1, and starting at 1/1000 and compares the outputs
